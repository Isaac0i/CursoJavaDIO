# Curso Java Backend - DIO

Repositório contendo as atividades, exercícios e projetos desenvolvidos durante o curso de **Java Backend** realizado pela DIO (Digital Innovation One).

Este projeto representa uma etapa importante na consolidação dos meus conhecimentos em desenvolvimento backend com Java.

---

## Objetivo

Organizar e documentar as práticas realizadas ao longo do curso, servindo como:

-  Registro de aprendizado
-  Consolidação de conceitos fundamentais
-  Evidência prática de evolução técnica
-  Material de consulta futura

---

## Estrutura do Repositório

O repositório está organizado conforme os módulos e práticas realizadas durante o curso, incluindo:

- `TrainingDio` → Exercícios e fundamentos da linguagem Java  
- `DioSpring/primeiros-passos` → Introdução ao ecossistema Spring  

Cada diretório contém implementações práticas baseadas nas aulas e desafios propostos.

---

## Tecnologias Utilizadas

- Java
- Spring Framework (módulos iniciais)
- Git & GitHub
- IntelliJ IDEA

---

## Conceitos Trabalhados

Durante o curso foram abordados temas como:

- Programação Orientada a Objetos (POO)
- Estruturas de dados e Collections
- Boas práticas de organização de código
- Fundamentos de desenvolvimento backend
- Introdução ao Spring

---

## Evolução

Este repositório demonstra minha progressão no aprendizado de Java backend, desde conceitos fundamentais até a introdução ao desenvolvimento com Spring.

---

## Observação

O foco deste repositório é educacional e prático, refletindo minha jornada de aprendizado na construção de aplicações backend com Java.
